# MedveGoshi Zoo — экспериментальная коллекция питомцев и проверок

**План продолжения:** [HANDOFF.md — ТЗ, приоритеты P0–P2, чек-листы, критерии приёмки и совместимость IPS/AMOLED V1](HANDOFF.md).

**P0 — подключаемая графика (экспериментально):** [полная инструкция](tools/README.md) · [конвертер](tools/build_sprites.py) · [MicroPython-загрузчик](sprites.py) · [предпросмотр](tools/preview_sprites.py) · [установка IPS](tools/install_pack.py). На IPS предусмотрено автоматическое использование корректного пакета и возврат к штатной графике при ошибке. Проверено на хостовых тестах, **не проверено на физической плате**; AMOLED V1 по-прежнему не поддерживается.

Этот каталог позволяет изучать открытые проекты Тамагочи, переносить полезные
тесты и постепенно включать **дополнительных персонажей** в MedveGoshi,
не меняя базовую игровую логику.

## Уже включено: Пип

**Пип** — одиннадцатый, необязательный персонаж в выборе героев игры.
Карамелька и остальные десять персонажей никуда не исчезли.
Пип получает штатные режимы «Уход», «Жизнь», «Гулять», возраст, сохранение
и общую нейросеть Capigoshi. Для Пипа добавлены русские реплики.

В `pip/face.py` находится **свой лёгкий процедурный рендерер**, вдохновлённый
выразительными глазами [Pip-KeyPet](https://github.com/NovikovVisuals/Pip-KeyPet)
(David Novikov, MIT). Это **не официальный Пип**, не порт оригинального
3D-C-рендерера и не копия его графических файлов. Мы намеренно не
используем большой C-рендерер, поскольку игра работает на MicroPython.

Пип рисуется тем же интерфейсом графических примитивов, что и остальные герои:
`ellipse`, `rect`. Поэтому он предусмотрен для **IPS 240×284**.
Поддержка AMOLED V1 появится после аппаратного переноса всей игры.

**Важное поведение оригинального Capigoshi:** смена персонажа через меню
начинает жизнь нового питомца с яйца и заменяет состояние активного питомца.
Выбор Пипа не должен происходить без подтверждения.

### Установка

Полная русская IPS-прошивка:
```bash
sh install.sh --board ips --port /dev/ttyACM0
```

Обновление файлов уже установленной IPS без стирания сохранений:
```bash
sh install.sh --board ips --port /dev/ttyACM0 --files-only
```

`deploy.sh` переносит **только** `zoo/__init__.py`,
`zoo/pip/__init__.py` и `zoo/pip/face.py`.
Исходные C/C++ тесты и документы не копируются в память устройства.

AMOLED V1 пока **не поддерживается**; защита в `install.sh` остаётся.

## Тесты: живые и эталонные

- `tests/test_zoo_pip.py` — **наши исполняемые тесты**: эмоции Пипа,
  устойчивость рисунка, 11 персонажей, русские реплики, каталог лицензий,
  отсутствие смешивания тестов с прошивкой.
- `tests/test_brain_integrity.py` — **наши исполняемые тесты**: сохранение резервной копии,
  повреждённые заголовки и контрольные суммы, отсечение битых файлов даже
  при пересчитанном CRC32. По результатам усилен загрузчик `companion/placa.py`.
- `tests/test_renderer_integration.py` — **настоящий вызов `desenho.personagem()`**
  через имитацию IPS-кадрового буфера: проверяет отрисовку всех 11 героев,
  включая Пипа, при нескольких состояниях глаз и рта.
- `upstream/pip/sim/` — оригинальные MIT-тесты Pip-KeyPet
  (мордашка, лабиринт, состояние питомца).
- `upstream/giraffegotchi/` — оригинальные MIT-тесты потребностей,
  ночного сна и расчёта солнца.
- `upstream/tamapetchi/` — оригинальные MIT-тесты времени суток и
  резервного копирования/восстановления.

**Оригинальные тесты Pip-KeyPet на C запускаются отдельно** с
сохранёнными исходниками C-движка:
`sh zoo/upstream/pip/run_tests.sh`. Они проверяют оригинальный C-рендерер,
лабиринт и логику питомца, **не** наш MicroPython-рендерер.
Оригинальные тесты Giraffegotchi и TamaPetchi пока хранятся как
справочные C++ исходники и не запускаются без своих окружений.

Запуск адаптированных тестов:
```bash
python3 -m unittest discover -s zoo/tests -p 'test_*.py'
```

Они также включены в GitHub Actions проекта.

## Лицензирование

Оригинальные справочные файлы скопированы **без изменений** из указанных
MIT-репозиториев. Полные авторские лицензии сохранены в каждой папке
`upstream/<проект>/LICENSE`. Точные коммиты и пути — в [UPSTREAM.md](UPSTREAM.md).

**В Zoo не скопировано ни одного чужого PNG/PSD/WAV.** Лицензии кода и
авторские права на графику могут различаться. В частности, у Catode32
рисунки CC BY-NC-ND 4.0 и для изменяемых скинов не подходят; Pokémon из
TamaPoke не являются свободными изображениями. Каталог кандидатов —
[assets/README.md](assets/README.md).

Собственный Пип-подобный рендерер является частью MedveGoshi под MIT с
сохранённой благодарностью автору исходной идеи.
