## 0. Цель и неизменяемые требования

Создать расширяемый русскоязычный электронный питомец **MedveGoshi** на основе [Capigoshi](https://github.com/rjcaubit/capigoshi), который поддерживает **две платформы одной игровой логикой**:

| Профиль | Аппаратная платформа | Статус на дату handoff |
|---|---|---|
| `ips` | Waveshare ESP32-S3-Touch-LCD-1.83, IPS **ST7789 240×284**, тач **CST816D** | Исходная платформа Capigoshi. Русификация подготовлена в PR #2; реальная русская сборка ещё требует проверки на устройстве |
| `amoled-v1` | Waveshare ESP32-S3-Touch-AMOLED-1.8 **V1**, AMOLED **SH8601 368×448**, тач **FT3168** | Не портировано, выбор в `install.sh` намеренно блокирует прошивку |
| `amoled-v2` | Другая аппаратная ревизия, **CO5300/CST820** | Не входить в объём первого порта |

**Нельзя:** заменить IPS-драйвер AMOLED-драйвером, сломать установку IPS; вести две расходящиеся копии `main.py`/`vida.py`; менять форматы `config.json`, `capi.json`, `brain.bin` без миграции; считать тесты на ПК доказательством работы физической платы; добавлять сторонние PNG/PSD/WAV без проверки прав.

**Можно:** новые необязательные персонажи/скины, независимые мини-игры, тестовые данные, графические адаптеры, аппаратно-специфичные драйверы за единым API. Оригинальные десять персонажей, включая Карамельку, должны сохраниться.

## 7. Правила разработки и оформления PR

1. Каждая функциональная тема — небольшой PR: **(A) sprite pipeline**, **(B) 1 новый персонаж**, **(C) эмоции Pip**, **(D) 1 мини-игра**, **(E) сохранения**, **(F) AMOLED V1**. Не объединять порт дисплея и глобальную переработку игровой логики в один PR.
2. Чужие источники под MIT: указать проект, автора, URL, commit SHA и сохранить уведомления. **Графику считать отдельным объектом авторских прав.**
3. Сохранить совместимость с оригинальными ID персонажей, существующими сохранениями, режимами и русской локализацией.
4. Никогда не переносить в прошивку целиком `zoo/upstream/`, `zoo/tests/`, PSD, host-скрипты и неиспользуемые PNG.
5. Все новые Python-модули для ESP32 — проверка доступности MicroPython API, профиля памяти и скорости; `typing`/большие зависимости/CPython-only библиотеки — только на ПК.
6. Для каждого PR: до/после, схема каталогов, список тестов, скриншот host preview, поддерживаемые платы, фактические замеры, ограничения, лицензии и инструкции отката.
