# Zoo: кандидаты на графику и звуки

**Здесь намеренно нет скопированных чужих изображений, PSD или WAV.**

Первый **собственный** набор можно создать без внешних PNG:
[Жирафик — восемь эмоций, генерация и установка](../giraffe/README.md).
Исходник — процедурный рисунок MedveGoshi под MIT, графический конвейер
только вдохновлён Giraffegotchi.
Изображения в открытом GitHub-репозитории не обязательно свободны:
временная доступность файлов и MIT-лицензия кода не гарантируют права
на отдельные изображения, товарные знаки или чужих персонажей.

| Репозиторий | Что есть | Решение для MedveGoshi |
|---|---|---|
| [Giraffegotchi](https://github.com/elliotboney/giraffegotchi/tree/main/img) | Наборы PNG для жирафа, сурка, фламинго, гепарда и папка утки | **Кандидат**: сначала проверить происхождение каждой картинки, затем конвертировать отдельным скриптом |
| [TamaFi](https://github.com/cifertech/TamaFi/tree/main/Ui%20Graphics) | PSD/PNG, анимации яйца и интерфейса | Проверить авторство конкретных файлов и сторонние источники |
| [DigiCat](https://github.com/aquascape123/digicat/blob/main/firmware/DigiCat/art.cpp) | Кот, нарисованный кодом из примитивов | MIT-код — интересная база для собственных процедурных персонажей |
| [Pip-KeyPet](https://github.com/NovikovVisuals/Pip-KeyPet/blob/main/ui/face.c) | Объёмные глаза, процедурный C-рендерер | В `zoo/pip/face.py` уже есть лёгкая оригинальная реализация идеи |
| [Catode32](https://github.com/moonbench/catode32) | Рисунки под CC BY-NC-ND 4.0 | **Не импортировать** в изменяемые/публичные наборы скинов |
| [TamaPoke](https://github.com/socquique/TamaPoke) | Спрайты Pokémon | **Не импортировать**: сторонняя интеллектуальная собственность и дополнительные ограничения лицензии |

Будущий импорт изображений требует записи в реестр: оригинальный URL
и commit SHA, автор/правообладатель, условия использования,
размеры/палитра, формат хранения и проверка на обеих дисплейных платформах.

**Важно:** добавленные файлы `zoo/upstream/` — исключительно
текстовые программные тесты с MIT-лицензией, не графические ассеты.
