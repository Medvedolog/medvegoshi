# MedveGoshi — разработка и проверка БЕЗ ESP32

**Наличие платы не требуется** для текущего этапа разработки.
Вместо аппаратной приёмки используется компьютерный автоматический
тестовый стенд, а точный статус отображается в CI и отчетах.

## Что уже проверяется без платы

- Регистрация всех 12 существующих персонажей и «временного 13-го»,
  подгружаемого из отдельной папки без правки движка.
- Русские строки, их длина, загрузка процедурных рисунков и откат при
  ошибках модуля или спрайта.
- Сохранение и восстановление данных: ошибки JSON, отсутствие плагина,
  отказ от перезаписи `capi.json`, запрет отключения активного питомца.
- Полный набор из **8 состояний Жирафика** (PNG → RGB565 и маска):
  нормальный, радостный, грустный, спящий, больной, удивлённый,
  кушающий и моргающий.
- Размер и контрольная сумма каждого кадра, восемь уникальных
  спрайтов, прозрачность, размер пакета, работа портативного декодера.
- Защита установщика: блокировка AMOLED V1 и отсутствие стирания
  Flash в файло-ориентированных командах.

## Как самостоятельно посмотреть результат

1. Откройте [проверки GitHub Actions](https://github.com/Medvedolog/medvegoshi/actions/workflows/verify-python.yml).
2. Откройте **последний успешный** запуск рабочей ветки
   `feature/russian-game-ui`.
3. Внизу страницы откройте раздел **Artifacts**.
4. Скачайте `medvegoshi-giraffe-preview-and-ips-pack` (ZIP).
5. Распакуйте архив и откройте:
   - `qa-ips/all_expressions.png` — все восемь эмоций на сетке
     **240 × 284**;
   - `qa-ips/report.md` — подробная проверка кадров на русском;
   - `qa-ips/report.json` — машиночитаемые результаты;
   - `qa-amoled-v1/all_expressions.png` — только **графический
     предпросмотр** на холсте 368 × 448;
   - `source/` — исходные PNG;
   - `ips/` — компилированные файлы RGB565+маска.
   
На телефоне достаточно открыть PNG. Для анализа работы интерфейса
и сенсора **это не заменяет плату**.

Если захочется повторить сборку на компьютере:

```bash
python3 -m pip install "Pillow>=10,<13"
python3 -m zoo.tools.generate_giraffe \
  --source-out /tmp/giraffe-source --pack-out /tmp/giraffe-ips
python3 -m zoo.tools.offline_qa \
  --pack /tmp/giraffe-ips --out /tmp/giraffe-qa --board ips
```

В `/tmp/giraffe-qa` будут `all_expressions.png`,
`report.md`, `report.json` и восемь отдельных PNG.

## Что мы НЕ можем проверить без физической платы

**Не пройдено и не помечается как пройденное:**

- Реальная загрузка ESP32-S3 и совместимость MicroPython/PSRAM.
- Порядок байтов/цвета на физическом ST7789.
- Отзывчивость тача CST816D, аудио, движение, RTC, зарядка/батарея.
- Реальный FPS, свободная оперативная память, нагрев, расход энергии.
- Сценарии физической потери питания и восстановление Flash.
- AMOLED V1 (SH8601/FT3168) — его драйвер/установщик пока не готовы.

**План:** продолжать кодирование, host-тесты и визуальные ревью.
Для итогового статуса hardware-tested достаточно позднее найти одного
добровольного владельца точной IPS-платы, предоставить ему безопасный
smoke-тест и получить диагностический отчёт. Пока такого тестировщика
нет, `main` не объявляется аппаратно проверенным релизом.

Автоотчёт гарантирует **только проверку ресурсов на компьютере**,
не FPS, не совместимость электроники и не успешную прошивку.

См. [ТЗ](HANDOFF.md), [Zoo Registry](REGISTRY.md),
[восстановление сохранений](RECOVERY_RU.md).
