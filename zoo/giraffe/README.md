# Жирафик — первый оригинальный персонаж нового Zoo

Жирафик добавлен как **12-й персонаж** MedveGoshi, без заимствования
внешних изображений. Исходный рисунок — собственный процедурный
`zoo/giraffe/face.py` (рисуется из эллипсов, прямоугольников и дуг).
Задумка с дополнительными животными и обработкой поз вдохновлена
[Giraffegotchi](https://github.com/elliotboney/giraffegotchi), но ни один
PNG из этого проекта сюда не скопирован.

## Что работает

- В выборе животных появляется **Жирафик**, внутренний ID `girafa`.
- Русские фразы, эмоции, сон и штатные игровые механики.
- Без загруженных PNG он **автоматически рисуется процедурно**.
- Офлайновый генератор делает восемь оригинальных кадров PNG с
  общим якорем и собирает готовый пакет RGB565+маска для IPS.
- Пакет **не включён автоматически в прошивку**: пользователь сам решает,
  устанавливать ли детализированные кадры. В случае ошибки ресурса
  остаётся исходный процедурный Жирафик.

**Важно:** переключение животного в существующей игре создаёт нового
питомца с яйца и сбрасывает состояние активного питомца после подтверждения.
Не выбирайте Жирафика вместо прежнего питомца без сохранения нужных данных.

## Сборка ресурсов на компьютере

Установите Python и Pillow (на компьютере, не на ESP32):

```bash
python3 -m pip install "Pillow>=10,<13"
python3 -m zoo.tools.generate_giraffe \
  --source-out /tmp/giraffe-source \
  --pack-out /tmp/giraffe-ips
```

Генератор создаёт `normal`, `happy`, `sad`, `sleeping`, `sick`,
`surprised`, `eating` и `blink` — восемь прозрачных PNG на одном холсте
160×168, а затем восемь кадров RGB565 **120×144**, маски и `manifest.json`.
Входные файлы сохраняются отдельно: генератор **отказывается
перезаписывать непустой каталог**. Перед повторной сборкой выберите новый
каталог либо вручную удалите только свой временный выходной каталог.

Предпросмотр реального скомпилированного кадра на холсте IPS:

```bash
python3 -m zoo.tools.preview_sprites --pack /tmp/giraffe-ips \
  --frame happy --board ips --out /tmp/giraffe-ips.png
```

**Это PNG-предпросмотр, не фото дисплея.**

## Установка на исходный IPS

Сначала необходима русская прошивка с поддержкой Zoo из текущей ветки
и драйвером исходного ST7789 (IPS 240×284). Для сохранения существующего
питомца используйте обновление файлов:

```bash
sh install.sh --board ips --port /dev/ttyACM0 --files-only
```

Порт замените на действительный, например `COM5` на Windows.
Для установки необязательного sprite-pack:

```bash
python3 -m zoo.tools.install_pack --pack /tmp/giraffe-ips \
  --board ips --port /dev/ttyACM0 --dry-run
python3 -m zoo.tools.install_pack --pack /tmp/giraffe-ips \
  --board ips --port /dev/ttyACM0
```

Установщик проверяет manifest, размеры и SHA256. Он пишет только
`/zoo/packs/girafa/` и **не стирает всю Flash**. Следует остановить игру
на время передачи ресурсов и перезагрузить плату после загрузки пакета.
Отсутствие ресурса не мешает процедурному Жирафику работать.

## Готовые ZIP-артефакты GitHub Actions

В workflow **Python and Cyrillic checks** на ветке
`feature/zoo-giraffe-first-pack` собирается артефакт
`medvegoshi-giraffe-preview-and-ips-pack`.

В нём находятся исходные PNG, собранный IPS-пакет, графический пакет и
предпросмотр AMOLED V1 (только для оценки внешнего вида).
Это не готовая прошивка и не релиз для AMOLED. Пакеты можно скачать
со страницы успешного GitHub Actions run.

## AMOLED V1

Можно собрать вариант графики 192×224 и посмотреть его на холсте 368×448:

```bash
python3 -m zoo.tools.generate_giraffe \
  --source-out /tmp/giraffe-source-amoled \
  --pack-out /tmp/giraffe-amoled --target amoled-v1
python3 -m zoo.tools.preview_sprites --pack /tmp/giraffe-amoled \
  --frame happy --board amoled-v1 --out /tmp/giraffe-amoled.png
```

**Это не поддержка платы SH8601/FT3168.** Установщик AMOLED V1 остаётся
заблокированным до реализации и проверки аппаратного порта.

## Испытания и ограничения

```bash
python3 -m unittest discover -s zoo/tests -p 'test_giraffe_pack.py'
```

Автотесты проверяют восемь отличающихся кадров, детерминизм, права на
собственный рисунок, конвертацию, формат бинарных ресурсов, установщик,
отрисовку на mock-framebuffer и сохранение других персонажей.

Не проверено на реальном IPS: скорость отрисовки, расход PSRAM/Flash,
поведение `framebuf.blit`, переключение анимаций, сон, нагрев и
потребление. До испытаний PR оставляем **черновиком**.

**Происхождение:** собственный рисунок MedveGoshi, первоначальный код
[закреплён в GitHub](https://github.com/Medvedolog/medvegoshi/blob/73788e25b273da5f6bf444c19ecee697781598dd/zoo/giraffe/face.py);
лицензия MIT проекта. Giraffegotchi указан в благодарностях за
архитектурную идею, его внешние PNG не импортированы.
