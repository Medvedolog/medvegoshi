# MedveGoshi Zoo — экспериментальная коллекция питомцев и проверок

**Без физической платы:** [автономный тестовый стенд и визуальные отчёты Жирафика](OFFLINE_QA_RU.md). Все восемь эмоций публикуются в GitHub Actions вместе с проверенными RGB565-ресурсами; реальные IPS/AMOLED не тестировались.

**Восстановление и безопасное отключение:** [инструкция по защите питомца и USB-восстановлению](RECOVERY_RU.md). При отсутствии активного модуля Zoo игра останавливается без перезаписи сохранений.

**План продолжения:** [HANDOFF.md — ТЗ, приоритеты P0–P2, чек-листы, критерии приёмки и совместимость IPS/AMOLED V1](HANDOFF.md).

**Реализована подключаемая архитектура Zoo v1:** [REGISTRY.md — формат модуля, создание нового питомца без правок игрового ядра, безопасная установка и тест стороннего героя](REGISTRY.md).
Игровой каталог теперь читает `zoo/registry.py`, Пип, Жирафик и Бйорни
определяются файлами `zoo/animals/<id>/manifest.json`.
Новые персонажи обнаруживаются автоматически **после перезапуска**.
Смена друга загружает его отдельный слот; старые общие файлы мигрируют
копированием без удаления. Отключать активного героя по-прежнему нельзя.
Миграция и переключение проверены на ПК, аппаратная IPS ещё не проверена.


**P0 — подключаемая графика (экспериментально):** [полная инструкция](tools/README.md) · [конвертер](tools/build_sprites.py) · [MicroPython-загрузчик](sprites.py) · [предпросмотр](tools/preview_sprites.py) · [установка IPS](tools/install_pack.py). На IPS предусмотрено автоматическое использование корректного пакета и возврат к штатной графике при ошибке. Проверено на хостовых тестах, **не проверено на физической плате**; AMOLED V1 по-прежнему не поддерживается.

Этот каталог позволяет изучать открытые проекты Тамагочи, переносить полезные
тесты и постепенно включать **дополнительных персонажей** в MedveGoshi,
не меняя базовую игровую логику.

## Бйорни — тринадцатый персонаж

Пиксельный медвежонок-программист с клавиатурой: 44 кадра для ходьбы в обе
стороны, прыжков, приветствия, реакции на заботу, печати и размышлений.
Отдельные позы показывают сонливость, сон, голод, еду, болезнь и испуг.
Поза не меняет правила игры: стандартные кормление, сон, возраст, звуки,
физика прыжка и отдельное сохранение сохраняются.

Графика создана для проекта с помощью генерации и адаптирована к размерам
игры. [Исходный лист](assets/bjorni-poses.png) остаётся на ПК; приложение
получает только компактные прямоугольники в `animals/bjorni/face.py`.
Проверка пересборки: `python -m zoo.tools.build_bjorni_frames --check`.
Рисование работает в хост-тестах для IPS и эмуляторе AMOLED V1. Физическая
плата пока не проверена, установка AMOLED по-прежнему заблокирована.

## Добавлен: Жирафик — двенадцатый персонаж

**[Подробная инструкция, восемь эмоций и сборка IPS-пакета](giraffe/README.md).**
Жирафик (`girafa`) подключается через `zoo/animals/girafa/manifest.json`,
использует собственный рисунок на примитивах
`zoo/giraffe/face.py`. Процедурный рисунок работает без PNG. На компьютере
из него воспроизводимо создаются восемь поз в формате PNG и отдельные
опциональные RGB565-ресурсы. Это не чужие спрайты Giraffegotchi,
а оригинальный персонаж MedveGoshi.

**На плате пока не испытан.** Для исходной IPS 240×284 доступна
экспериментальная установка; для AMOLED V1 подготовлен только офлайновый
предпросмотр, не готовая прошивка. Медведь и мухомор в этот PR не входят.

## Уже включено: Пип

**Пип** — одиннадцатый, необязательный персонаж, подключённый через
`zoo/animals/pip/manifest.json`.
Карамелька и остальные десять персонажей никуда не исчезли.
Пип получает штатные режимы «Уход», «Жизнь», «Гулять», возраст, сохранение
и общую нейросеть Capigoshi. Для Пипа добавлены русские реплики.

В `pip/face.py` находится **свой лёгкий процедурный рендерер**, вдохновлённый
выразительными глазами [Pip-KeyPet](https://github.com/NovikovVisuals/Pip-KeyPet)
(David Novikov, MIT). Это **не официальный Пип**, не порт оригинального
3D-C-рендерера и не копия его графических файлов. Мы намеренно не
используем большой C-рендерер, поскольку игра работает на MicroPython.

Пип рисуется тем же интерфейсом графических примитивов, что и остальные герои:
`ellipse`, `rect`. Поэтому он предусмотрен для **IPS 240×284**.
Поддержка AMOLED V1 появится после аппаратного переноса всей игры.

**Смена питомца в MedveGoshi:** сохранение, возраст и обучаемый мозг
хранятся в `pet_saves/<id>/`. Новый друг впервые появляется из яйца;
при возврате загружается прежнее состояние. «Сброс» — отдельное действие
с подтверждением: оно начинает заново только жизненный цикл текущего друга,
не стирая его обучаемый мозг или сохранения других героев.

### Пип со своим характером: прототип для ПК

```bash
python -m zoo.pip.replay
python -m zoo.pip.replay --json
python -m zoo.tools.preview_pip_voice pip-voice-demo.wav
```

На Linux и macOS нужны CPython 3 и C-компилятор (`cc` либо `CC`). Настольный сценарий
компилирует оригинальный `pet.c`, кормит Пипа, гладит, укладывает спать и
прокручивает время. Для каждого шага выводятся потребности, настроение и
его причина. Проверка сохранения выполняется во **временном** отдельном
`pip-state.json`: она восстанавливает Пипа и сравнивает дальнейшее
поведение с непрерывным запуском. Формат сохранения привязан к версии
настольного моста; он не заменяет `capi.json` или `brain.bin` на плате.

[Голос Пипа](upstream/pip/VOICE.md) — оригинальные синтезированные эмоции,
а не произнесённые русские слова. WAV готовится на компьютере. Эти
инструменты не меняют существующих питомцев, игровой `main.py` и
установщик, не проверены на физической плате. Следующий этап:
подключить отдельный слот и поведение Пипа к игровому меню после
интеграции аппаратного слоя; озвучивание через динамик проверять отдельно.

### Установка

Полная русская IPS-прошивка:
```bash
sh install.sh --board ips --port /dev/ttyACM0
```

Обновление файлов уже установленной IPS без стирания сохранений:
```bash
sh install.sh --board ips --port /dev/ttyACM0 --files-only
```

`deploy.sh` переносит **только** `zoo/__init__.py`,
`zoo/pet_slots.py`, `zoo/switch_pet.py`,
`zoo/pip/__init__.py`, `zoo/pip/face.py`, `zoo/giraffe/__init__.py`,
`zoo/giraffe/face.py`, `zoo/sprites.py`, `zoo/registry.py` и
автоматически **все корректно подготовленные папки**
`zoo/animals/<id>/`. Необязательные PNG/RGB565-пакеты
ставятся отдельно и в прошивку по умолчанию не включаются.
Исходные C/C++ тесты и документы не копируются в память устройства.

AMOLED V1 пока **не поддерживается**; защита в `install.sh` остаётся.

## Тесты: живые и эталонные

- `tests/test_zoo_pip.py` — **наши исполняемые тесты**: эмоции Пипа,
  устойчивость рисунка, 12 персонажей, русские реплики, каталог лицензий,
  отсутствие смешивания тестов с прошивкой.
- `tests/test_brain_integrity.py` — **наши исполняемые тесты**: сохранение резервной копии,
  повреждённые заголовки и контрольные суммы, отсечение битых файлов даже
  при пересчитанном CRC32. По результатам усилен загрузчик `companion/placa.py`.
- `tests/test_renderer_integration.py` — **настоящий вызов `desenho.personagem()`**
  через имитацию IPS-кадрового буфера: проверяет отрисовку всех 12 героев,
  включая Пипа, при нескольких состояниях глаз и рта.
- `upstream/pip/sim/` — оригинальные MIT-тесты Pip-KeyPet
  (мордашка, лабиринт, состояние питомца).
- `upstream/giraffegotchi/` — оригинальные MIT-тесты потребностей,
  ночного сна и расчёта солнца.
- `upstream/tamapetchi/` — оригинальные MIT-тесты времени суток и
  резервного копирования/восстановления.

**Оригинальные тесты Pip-KeyPet на C запускаются отдельно** с
сохранёнными исходниками C-движка:
`sh zoo/upstream/pip/run_tests.sh`. Они проверяют оригинальный C-рендерер,
лабиринт и логику питомца, **не** наш MicroPython-рендерер.
Оригинальные тесты Giraffegotchi и TamaPetchi пока хранятся как
справочные C++ исходники и не запускаются без своих окружений.

Запуск адаптированных тестов:
```bash
python3 -m unittest discover -s zoo/tests -p 'test_*.py'
```

Они также включены в GitHub Actions проекта.

## Лицензирование

Оригинальные справочные файлы скопированы **без изменений** из указанных
MIT-репозиториев. Полные авторские лицензии сохранены в каждой папке
`upstream/<проект>/LICENSE`. Точные коммиты и пути — в [UPSTREAM.md](UPSTREAM.md).

**В Zoo не скопировано ни одного чужого PNG/PSD/WAV.** Лицензии кода и
авторские права на графику могут различаться. В частности, у Catode32
рисунки CC BY-NC-ND 4.0 и для изменяемых скинов не подходят; Pokémon из
TamaPoke не являются свободными изображениями. Каталог кандидатов —
[assets/README.md](assets/README.md).

Собственный Пип-подобный рендерер является частью MedveGoshi под MIT с
сохранённой благодарностью автору исходной идеи.
